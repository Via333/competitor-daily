# 美国安防竞品雷达

一个可长期更新的美国安防市场竞品监控站，覆盖：

- Reolink（自有品牌基准）
- eufy Security
- Arlo
- SimpliSafe
- Ring
- Google Nest

站点以 Reolink 为自有基准，对比五家主要竞品，提供每日重点、品牌筛选、营销与声誉雷达、当前快照、近 7 天回顾、近 30 天趋势与永久历史归档。

## 查看网页

发布后访问：<https://via333.github.io/competitor-daily/>

## 添加新一期日报

1. 复制 `data/reports/2026-08-08.json`。
2. 将文件名和文件内的 `date` 改为新日期。
3. 更新重点信号、营销与声誉事件、品牌快照、7 天回顾和 30 天趋势。
4. 提交到 `main` 分支；GitHub Pages 会自动构建和发布。

页面会自动发现 `data/reports/` 下的所有 JSON 文件，并按日期倒序加入归档，无需手工维护日期列表。

## 数据口径

- 可验证事实优先链接到官方产品、新闻稿或支持页面。
- 自有品牌与竞品采用相同的证据、重要性和风险标注标准。
- 营销与声誉事件明确区分官方 / 品牌方、权威媒体、第三方监测与社区信号。
- 社区讨论只标记为“持续观察”或“弱信号”，不会直接写成品牌事实。
- 从第二期开始，新增、变化、结束和持续按上一期严格对比。
- 历史报告永久保留，不会被下一期覆盖。
